ICC2 FLOORPLAN UTILIZATION SCALING

Current Utilization:
106.3%

Target Utilization:
85%

--------------------------------------------------

Concept:

Utilization = Cell Area / Core Area

Cell area is fixed.

To reduce utilization:
Increase floorplan area.

--------------------------------------------------

Step 1: Compute Area Scaling

Area_new / Area_old = Current_Util / Target_Util

= 106.3 / 85
= 1.25

So floorplan area must increase by 1.25x

--------------------------------------------------

Step 2: Compute Coordinate Scaling

Scale Factor = sqrt(1.25)

s = 1.118

--------------------------------------------------

Step 3: Scale All Coordinates

Multiply every X and Y coordinate by 1.118

Examples:

200 -> 224
300 -> 336
150 -> 168
500 -> 560
