# crypro_top_Project
The crypto_top project is a high-performance ASIC cryptographic accelerator designed using 32nm CMOS technology. It contains around 30K standard cells.


-> Use cryto_manual to create the project in the project folder (or)

-> Website (Initial version): https://ajay-mallesh.github.io/crypro_top_manual_website/

############### All Normal Text / text document are created in "Notepad++". Please use that if any changes in text structures ################################

-> Link (Notepad++): https://notepad-plus-plus.org/downloads/v8.9.6/

*** Use "crypto_manual" wrt Tool directories and its creation scripts (Don't skip) ***

** Below are with respect to Project Folders ** (Not wrt Tool directories)

*** Make sure to have all the paths of ".lib, tech files (RC parasitic), CLIBs" are available in your "Tool Project Path"

Files and its path :

1. Synthesis Inputs :
	Path *
	     -> RTL (Folder) -> crypto_top.v
	     -> UPF (Folder) -> crypto_power.upf
	     -> sdc -> Constraints (Folder) -> Synthesis_only (Folder) -> constraints_mv.sdc
	
2. Synthesis Script :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> synthesis (Folder) -> dc_compile.tcl

3. Synthesis Outputs :
	     -> Generated automatically after synthesis 
	Path *
	     -> outputs (generated here)

4. Floorplan to PowerPlan :
	Path *
	     -> Netlist -> outputs/netlist_name.v (Generated by Synthesis)

	     -> voltage area script : 
			-> working_scripts (Folder) -> voltage_area_efficient -> voltage_area_efficient.tcl
	     -> upf :
			-> outputs/upf_name.upf (Generated by Synthesis)
	
	     -> Powerplan script :
			-> scripts (Folder) -> working_scripts (Folder) -> powerplan_working (Folder) -> powerplan_crypto_top.tcl

	     -> Scandef :
			-> outputs/scandef_file_name.scandef (Generated by Synthesis)

5. Placement :
	Path *
	     -> Scandef :
			-> outputs/scandef_file_name.scandef (Generated by Synthesis)

	     -> MCMM :
			-> Constraints (Folder) -> Timing_Analysis_PD (Folder) -> Separete_files (Folder) -> mcmm_setup.tcl
			-> Edit "mcmm_corners_modes.tcl" with proper paths

	     -> Placement Script :
			-> scripts (Folder) -> working_scripts (Folder) -> placement (Folder) -> placement_script.tcl

6. Upsize Cell :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> upsize_driver_cell (Folder) -> upsize_cell.tcl

7. Insert Buffer :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> Insert_Buffer (Folder) -> insert_buffer.tcl

8. Clock Tree Synthesis (CTS) :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> cts (Folder) -> cts_script.tcl
			-> Edit the cts_script with cts_include_refs.tcl "path"

9. Routing Script :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> routing (Folder) -> route.tcl

10. Signoff Script :
	Path *
	     -> scripts (Folder) -> working_scripts (Folder) -> signoff (Folder) -> signoff_script.tcl
